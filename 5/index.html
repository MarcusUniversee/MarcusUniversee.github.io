Part 1: Sampling Loops

Part 1.1: Implementing the Forward Process

In this section, I implemented the forward diffusion process. This involves adding Gaussian noise to an image over T time steps. At each time step t, we compute the noisy image $x_t$ from the previous image $x_{t-1}$ using the formula: $$x_t = \sqrt{1 - \alpha_t} x_{0} + \sqrt{1 - \alpha_t} \epsilon$$ where $\epsilon$ is sampled from a standard normal distribution, and $\alpha_t$ is a cumulative product gotten from stage_1.scheduler.alphas_cumprod.

Part 1.3: One-Step Denoising

We can use the stage 1 pretrained diffusion model to perform one-step denoising.

  1. Add noise with the forward method implemented in 1.1.
  2. Estimate noise by passing the noisy image and time step to the pretrained model.
  3. Remove the estimated noise from the noisy image to get the denoised image.
  4. Compare the denoised image with the original image.

Part 1.2.3: Denoising pure noise

We now repeat the same training process, but denoise on pure noise. We can see that the generated outputs is a blur, almost like a fusion of every number together. This is happening because we have almost the same inputs (pure noise), being trained to map to all 10 different outputs, so there is no relationship of input to output. Therefore, the lowest error becomes a blend of all the digits. However, this does pick up on some common patterns between all digits. For example, the right side of the blur is stronger than the left side since most digits have more substance on the right side than the left side.

Part 2.6: Training with your own data

In this section, we use the same method to train on our own captured dataset. One difference from the previous section is that the image resolution is significantly higher (over 10x), so I downscale the images when creating the dataset to save gpu memory and training time. Due to this, the focal lengths in the intrinsic matrix must also be downscaled by the same factor. For my data, I downscaled by 2x for training, and downscaled another 4x only when rendering images to png. Another difference is that I trained for 10000 iterations, double the previous section.
